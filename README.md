# ⚖️ TechDiff (テックディフ)

> **「不変の基礎」と「AI時代の応用差分」を可視化する進化型・技術＆知識辞典**  
> その知識は10年後も使える「本質」か、それともAIで代替された「過去の遺物」か？

---

## 💡 概要・背景

生成AIの急速な浸透やツールの仕様変更により、これまで当たり前だった「基礎的な作業や定石」が猛スピードで変化しています。  
しかし、すべてが変わるわけではありません。**「時代を超えて絶対に変わらない基礎（原理原則）」**の上に、**「AI時代の新しい応用（ワークフローの差分）」**が乗っかっているのです。

**TechDiff** は、過去のプロジェクト『[LexiCurve](https://github.com/kiyotakakita/LexiCurve)』のアーキテクチャをベースに改良し、あらゆる技術・ビジネス概念を**「不変の基礎」「古くなった情報」「AI時代の差分」**に分解して網羅する知的ダッシュボード（差分辞典）です。

---

## ✨ 主な機能

- 🌊 **知識の4段階・進化ストリーム (Evolution Stream)**
  - 検索したトピックを以下の4フェーズに分解してタイムライン形式で可視化します。
    1. **【1. 不変の基礎 (Core)】** AIがどれだけ進化しても人間が理解しておくべき本質・原理
    2. **【2. 従来の定石 (Legacy)】** AI以前に当たり前だった手動のワークフロー
    3. **【3. 古くなった情報 (Obsolete)】** 仕様変更やAIの台頭により非効率・不要になった古い作法
    4. **【4. AI時代の応用 (AI-Era Diff)】** 不変の基礎×AIで最速で成果を出す現在の新標準
- 🔄 **セマンティック・シフト（境界線ハイライト）**
  - 「人間が学ぶべき基礎」と「AIに任せるべき作業」の境界線がどこにあるのかを明確に比較・ハイライト。
- 🛡️ **知識の陳腐化・アップデート診断 (Obsolete Checker)**
  - 「昔のやり方のまま止まっていないか？」を判定し、実践的なアップデート指針を提示。
- 📊 **不変度＆AI変革マップ（ベルカーブ・プロット）**
  - そのトピックが「AIで激変中の領域」なのか、「10年後も変わらない普遍の基礎領域」なのかを直感的にプロット。
- 🔥 **AI激変トピックスキャン (Google Gemini連動)**
  - ボタン1つで、「基礎は不変だが、AI時代でアプローチが劇的に変化している重要トピック」を自動抽出。

## 🛠️ 技術スタック

- **Frontend:** React / Vite / TypeScript
- **Styling:** Tailwind CSS / Lucide Icons
- **AI & API:** Google Gemini API (gemini-flash-latest)
- **Deployment:** Vercel

---

## 🚀 ローカルでの動かし方

1. リポジトリのクローン
   `git clone https://github.com/kiyotakakita/TechDiff.git`
2. パッケージのインストール
   `cd TechDiff && npm install --force`
3. APIキーの設定
   `.env` ファイルに `VITE_GEMINI_API_KEY` を設定（またはアプリ画面右上の設定から直接入力）
4. 開発サーバーの起動
   `npm run dev`
