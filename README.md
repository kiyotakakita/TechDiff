# ⚖️ TechDiff (テックディフ)

> **「不変の基礎」と「AI時代の応用差分」を可視化する進化型・技術＆知識インデックス**  
> 用語そのものの網羅解説は外部コモンズ（Wikipedia・MDN等）へ委譲し、「何が古くなり、何が変わらないか」の独自索引とキュレーション（アクセプト）に特化した知的ダッシュボード。

## 💡 コンセプト・設計思想

基礎的な技術や業務知識にもAIの応用が入り込み、「どこまでが普遍の基礎で、どこからがAI時代で変わった作法なのか」の境界線が曖昧になっています。

**TechDiff** は、既存の辞典サイトの劣化コピー（用語の意味を自前で抱え込むこと）を作らないために、以下のアーキテクチャを採用しています。

1. **📚 基礎用語の辞書解説は「外部コモンズ」へリンク委譲**
   - 各単語の詳細画面から **Wikipedia / IT用語辞典 e-Words / MDN Docs** へワンタップで直行できる外部リンクを自動生成。基礎定義の網羅性は外部サイトに任せます。
2. **🧭 独自の「5段階・差分インデックス体系」で分類**
   - ありきたりな分野別分類ではなく、「AIによって人間の関わり方がどう変化したか」という独自の5段階軸で知識をマッピングします。
3. **✅ 候補スキャン ＆ アクセプト（承認）ワークフロー**
   - AIが抽出した差分候補や分析結果を見て、自分の辞書に残す価値があるものを「アクセプト（採用）」または「却下」して選別します。

## 📊 独自の5段階・差分インデックス体系

マップの横軸（左から右）は、知識の不変度とAI変革のパターンを表しています。

1. **【1. 手順の消滅 (AI丸投げ)】**
   - 概念（基礎）の理解は必要だが、手作業で書く・作る手順そのものはAIに代替された領域（例：正規表現の記述、定型コード生成）。
2. **【2. 作法の逆転 (役割180°変化)】**
   - 「0から1を手作りする」から「AIが出した100を検証・軌道修正する」へと人間の役割が逆転した領域（例：エラー解決・デバッグ手法）。
3. **【3. UI・仕様の流動 (迷子注意)】**
   - 裏側の基礎概念は同じなのに、ツールの画面配置や設定作法が頻繁に変わって迷子になりやすい領域（例：GitHubのUI・Actions運用）。
4. **【4. 基礎の重要度倍増 (人間の急所)】**
   - AIが量産できる時代だからこそ、人間側の「基礎理解・設計力」がないと破綻するため価値が跳ね上がった領域（例：Gitのリポジトリ設計・セーブポイント管理）。
5. **【5. 不変の原理 (10年後も不変)】**
   - AI時代になろうがツールが変わろうが、一切古びない絶対的な基礎理論・メンタルモデル（例：情報設計と独自の索引体系）。

## ✨ 4段階・進化ストリーム（各トピックの解剖軸）

すべてのトピックは、以下の4つの時間軸・構造に分解されて記録されます。
- **【1. 不変の基礎 (Core)】** AIが進化しても人間が理解しておくべき本質・原理
- **【2. 従来の定石 (Legacy)】** AI以前に当たり前だった手動のワークフロー
- **【3. 古くなった情報 (Obsolete)】** 仕様変更やAI台頭により非効率・不要になった古い作法
- **【4. AI時代の応用 (AI-Era Diff)】** 不変の基礎×AIで最速で成果を出す現在の新標準

## 🚀 ローカルでの動かし方

1. クローン: `git clone https://github.com/kiyotakakita/TechDiff.git`
2. インストール: `cd TechDiff && npm install --force`
3. APIキー設定: `.env` に `VITE_GEMINI_API_KEY` を設定（またはWeb画面右上の設定アイコンから直接入力）
4. 起動: `npm run dev`
